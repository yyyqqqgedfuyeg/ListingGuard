# ListingGuard 敏感词、违禁词与夸大描述合规规范手册

本手册收录电商上架、种草推广、营销文案创作中的敏感词、极限词、夸大宣传用语及平台违禁词库，由 `ListingGuard` Hook 安全拦截系统实时加载与匹配。

---

## 1. 绝对化用语 / 极限词 (Extreme / Absolute Claims)

依据《中华人民共和国广告法》第九条第三项规定，广告不得使用“国家级”、“最高级”、“最佳”等绝对化用语。

### 1.1 违规词库清单
| 违规类型 | 违禁敏感词 | 处置动作 (Hook Action) | 推荐合规替代词 |
| :--- | :--- | :--- | :--- |
| 首位/顶级类 | `全网第一`、`全网首发`、`顶级`、`最好`、`最佳`、`全国第一`、`世界第一` | **BLOCK (直接拦截)** | `精选好物`、`热销推荐`、`备受好评` |
| 极致/终极类 | `极致`、`终极`、`史无前例`、`前无古人`、`绝对`、`必选`、`独一无二` | **REQUIRE_APPROVAL (人工审核)** | `用心打磨`、`品质推荐`、`优选品质` |
| 独家/专属类 | `独家`、`仅此一家`、`全网唯一`、`无可替代` | **REQUIRE_APPROVAL (人工审核)** | `自主研发`、`品牌特选` |
| 绝对承诺类 | `100%纯天然`、`100%有效`、`完美无瑕`、`彻底解决`、`永不褪色` | **BLOCK (直接拦截)** | `天然萃取配方`、`助您改善`、`耐用材质` |

## 2. 医疗功效与虚假宣传 (False Medical & Functional Efficacy)

依据《广告法》第十七条，除医疗、药品、医疗器械广告外，禁止其他任何广告涉及疾病治疗功能，并不得使用医疗用语或者易使推销的商品与药品、医疗器械相混淆的用语。

### 2.1 违规词库清单
| 违规类型 | 违禁敏感词 | 处置动作 (Hook Action) | 说明与法规依据 |
| :--- | :--- | :--- | :--- |
| 根治/治愈类 | `治愈`、`根治`、`彻底消除`、`药到病除`、`永不复发` | **BLOCK (直接拦截)** | 普通商品/食品/化妆品禁止宣称任何疾病治愈效果 |
| 药效/疗效类 | `药效`、`疗效显著`、`消炎杀菌`、`化瘀止痛`、`抗病毒` | **BLOCK (直接拦截)** | 属于医疗术语，非药品不得使用 |
| 慢性病治疗 | `降血压`、`降血糖`、`降三高`、`降血脂`、`溶栓` | **BLOCK (直接拦截)** | 保健食品或普通食品禁止宣称治疗三高 |
| 严重疾病类 | `防癌`、`抗癌`、`治疗近视`、`再生软骨`、`修复视网膜` | **BLOCK (直接拦截)** | 涉及严重疾病虚假宣传，属于一票否决严重违规 |
| 虚假生发减肥 | `月瘦30斤`、`3天暴瘦`、`永久生发`、`30天生发神水` | **BLOCK (直接拦截)** | 夸大功效，严重违背生理常识与广告真实性原则 |

## 3. 价格欺诈与虚假促销 (Price Fraud & Misleading Promotion)

依据《明码标价和禁止价格欺诈规定》第十六条至第十九条，经营者不得虚构原价、虚假折价、不履行价格承诺。

### 3.1 违规词库清单
| 违规类型 | 违禁敏感词 | 处置动作 (Hook Action) | 说明与合规要求 |
| :--- | :--- | :--- | :--- |
| 虚构原价 | `原价9999现价9.9`、`原价[高价]现仅售[极低价]` | **BLOCK (直接拦截)** | 原价必须真实有成交记录，禁止虚构划线价 |
| 甩卖夸张话术 | `跳楼大甩卖`、`亏本甩卖`、`倒闭清仓`、`老板跑路` | **REQUIRE_APPROVAL (人工审核)** | 扰乱正常市场价格秩序，损害平台营商环境 |
| 虚假倒计时 | `仅此一天`、`最后1小时`、`永不再有` (常态挂载) | **REQUIRE_APPROVAL (人工审核)** | 促销时限必须真实准确，不得欺骗诱导消费者 |

## 4. 平台查禁与违禁品 (Prohibited Goods & Platform Blacklist)

包含国家管制违禁品、侵犯知识产权假货、以及操纵评价行为。

### 4.1 违规词库清单
| 违规类型 | 违禁敏感词 | 处置动作 (Hook Action) | 说明 |
| :--- | :--- | :--- | :--- |
| 违禁管制物品 | `枪支`、`弹药`、`迷药`、`窃听器材`、`毒品`、`管制刀具` | **BLOCK (直接拦截并告警)** | 触犯国家法律红线，一经发现即刻阻断并上报 |
| 仿冒与侵权 | `高仿`、`A货`、`1:1复刻`、`原单正品代工`、`精仿` | **BLOCK (直接拦截)** | 违反商标法与平台知识产权保护规范 (如 eBay VeRO) |
| 操纵评价与导流 | `好评返现`、`加微信退款`、`私聊返红包`、`五星好评发红包` | **BLOCK (直接拦截)** | 严重破坏平台信誉评价体系，属于违规操纵评价 |

## 5. 夸大营销修辞 (Exaggerated Marketing Claims)

在种草文案和推广帖子中，滥用夸张修辞会误导消费者并触发平台风控审核。

### 5.1 常见夸大用语
- `一秒见效` / `瞬间吸收变白` / `奇迹般复原`
- `用一次年轻10岁` / `逆龄神器` / `返老还童`
- `神仙颜值` / `炸裂推荐` / `买它就对了闭眼入` (轻度提示 WARNING)

## 6. 系统 Hook 拦截与联动逻辑

1. **Tool Pre-Hook 拦截**：
   - 任何涉及商品 (`db_create_product` / `db_update_product`) 或关联帖子 (`db_create_post` / `db_update_post`) 的写入操作，自动触发 `check_post_compliance_hook` 或 `check_product_compliance_hook`。
   - 若命中 `BLOCK` 级别词汇（如极限词、虚假疗效、价格欺诈、违禁品），直接拒绝入库并抛出合规拦截异常。
   - 若命中 `REQUIRE_APPROVAL` 级别，将实体状态置为 `PENDING_AUDIT` 并自动记录违规特征标签。
2. **Prompt Post-Hook 检查**：
   - 当调用 LLM 生成营销提示词或文案时，触发 `inspect_generated_prompt_hook`。
   - 自动扫描敏感词并提供安全消解方案（如将“全网第一”降级为“热销优选”），保障大模型输出安全可控。
